# ご当地名物帖

北海道から沖縄まで、47都道府県のご当地名物をまとめたHTMLページです。グルメ、お菓子・土産、工芸品の3種類に分けて、全部で約960品を収録しています。

## 内容

- 地方別(北海道、東北、関東、中部、近畿、中国、四国、九州・沖縄)に都道府県を並べています
- 各都道府県の番号は都道府県コード(JIS)に対応しています
- 都道府県ごとに、グルメ、お菓子・土産、工芸品の順で表示します

## 使い方

- 検索欄に県名や名物の名前(例: うどん、焼)を入れると、一致するものだけを表示します
- 「グルメ」「お菓子・土産」「工芸品」のボタンで、種類を絞り込めます
- 地方名のボタンを押すと、その地方の位置へ移動します
- 画面の明るさは、お使いの端末の設定(ライト/ダーク)に合わせて切り替わります

## ファイル

- `gotouchi-meibutsu.html` : ページ本体です。HTML、CSS、JavaScriptが1ファイルにまとまっています

## データの編集

名物のデータは `gotouchi-meibutsu.html` の中の `RAW` という配列にあります。1行が1都道府県で、次の形式です。

```
コード|県名|ローマ字|地方|グルメ|お菓子・土産|工芸品
```

各項目の中は「、」で区切ります。名物を足すときは、該当する項目の末尾に「、名物名」を付け足してください。

## 注意

- 名物は代表的なものを中心に、作成者の知識から選んでいます。ネットでの裏取りはしていません
- 販売状況や旬は、店舗や時期によって変わります
- 表示するフォント(Shippori Mincho、Zen Kaku Gothic New)はGoogle Fontsから読み込みます
